# あなたの業務コンテキスト(テンプレート)

このファイルは Sample02 の経費自動検知 Bot が AI 判定時に参照する **業務コンテキスト** のテンプレートです。

## 使い方

1. このファイルを `business_context.md`(同じディレクトリ内)としてコピー
2. 自分の事業内容に合わせて中身を書き換える
3. n8n ワークフローを再起動するか、変更後の最初のメール処理から自動で反映される

`business_context.md` は **gitignore 対象** にして、自分のリポでローカル管理する想定です(コードは公開、業務情報はローカル管理という Sample01 と同じ思想)。

---

## 業務の概要

ここにあなたの事業 / 個人事業 / フリーランス活動の内容を 1〜3 行で記述してください。

例:
> 業務自動化(n8n × Claude API)の実装事例公開と、それを起点とした個人事業主向けのコンサル/受託案件。

例:
> Web 制作受託(主に LP・コーポレートサイト)。WordPress + ヘッドレス CMS の構成が中心。クライアントは小規模事業者(年商〜5 億円規模)。

例:
> 中小企業向けの業務改善コンサルティング。製造業の DX 推進が主領域。社内研修・ツール選定支援・PoC 設計が主なサービス。

---

## 業務に直接関連するもの(按分 100% 推奨)

経費としてフルで計上できるカテゴリを箇条書きで列挙してください。AI はこれを参考に按分率を推奨します。

例(業務自動化の場合):
- LLM API 利用料(Anthropic / OpenAI 等)
- ワークフロー自動化ツール(n8n / Zapier / Make 等)
- 業務関連の技術書(Claude / n8n / プログラミング / システム設計 等)
- 業務用ドメイン(自社サイト / ショーケースサイト)
- クラウドホスティング(Vercel / Cloudflare / AWS 等、業務利用)

例(Web 制作の場合):
- デザインツール(Figma / Adobe CC 等)
- ホスティング・ドメイン(クライアント案件用 / 自社用)
- ストックフォト / フォントライセンス
- Web 制作関連の技術書

---

## 業務に部分的に関連するもの(按分 30〜70% 想定)

業務にも個人にも使うが、業務利用が一定割合あるカテゴリ。AI は内容に応じて中間値を推奨します。

例:
- 一般的なマネジメント書 / マーケ書(業務に役立つが個人読書も含む)
- 汎用 SaaS(Notion / Slack 個人プラン / GitHub Pro 等)
- コワーキングスペース利用料

---

## 業務無関係(按分 0%、自動スキップ推奨)

業務と無関係な購入。AI はこれらを 0% 推奨 + 「スキップ(ledger 追記なし)」を提案します。

例:
- 食品 / 日用品 / 家庭用品
- エンタメ系書籍(小説・漫画・趣味本)
- 個人旅行関連
- 衣料品(業務制服を除く)

---

## 補足ルール(任意)

AI 判定の補助情報として、運用ルールがあればここに記述してください。

例:
- Amazon の購入で 1 万円以上は手動確認(AI 判定だけで自動記録しない)
- 〜年〜月以前のメールは無視(過去メールの大量処理を避ける)
- 特定送信元(例: noreply@github.com)はすべて業務関連扱い

---

## 注意

- このファイルの内容は Claude API に **メール本文と一緒に送信** されます。社外秘情報や個人情報は含めないでください
- `business_context.md`(ローカル運用版)は **必ず gitignore 対象** にしてください
- このテンプレート(`.example.md`)はリポ公開用のサンプルなので、機微な情報は書かないでください
