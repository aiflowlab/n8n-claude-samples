# Sample01 入出力対比(代表 4 ケース、2026-05-08 実測)

n8n production webhook (`POST /webhook/sample01`) に testcases/inquiries.jsonl の 4 件を投入したときの実際の出力。
ドラフトはそのまま記事/X に載せる場合は署名「〇〇株式会社 カスタマーサポート」を実在しない名称に置換すること。

---

## ケース 1: 緊急トラブル(苦情・高)

### 入力メール

```
From: 田中健一 <tanaka@example.com>
Subject: 【至急】注文した商品が届かない

先週月曜に注文した商品(注文番号 #A-2389)が、明日の社内イベントで使用予定でしたが
本日朝になっても届いていません。明日の朝までに必要です。至急ご対応ください。
連絡が取れない場合はキャンセル・返金を希望します。
```

### 分類結果

| 軸 | 値 |
|---|---|
| category | 苦情 |
| urgency | 高 |
| sentiment | ネガティブ |
| recommended_response_deadline | 2時間以内 |

### ドラフト返信(Draft Urgent ルート)

```
ご不便をおかけし申し訳ございません。注文番号 #A-2389 のご件、直ちに配送状況を確認いたします。

明日朝のご使用というご事情を承知いたしました。本日中に最新の配送情報をお調べし、
可能な限り迅速な対応を検討させていただきます。つきましては、恐れ入りますが
現在のご連絡先電話番号をお知らせいただけますでしょうか。本日 16 時までに
お電話またはメールにて状況をご報告いたします。

配送遅延が確認された場合は、代替手段やキャンセル・返金についても含めて、
ご相談させていただきたく存じます。

〇〇株式会社 カスタマーサポート
```

→ 謝罪先行 + 具体アクション(本日 16 時報告)+ 代替案(キャンセル/返金)を明示。

## ケース 2: 標準的な見積依頼(見積・中)

### 入力メール

```
From: 山田花子 <yamada@corp.example.jp>
Subject: Web サイト制作のお見積りについて

貴社のサービスに興味を持ちご連絡しました。当社コーポレートサイトのリニューアルを
検討しており、概算見積りをいただきたく存じます。ページ数は 10〜15 ページ、
お問い合わせフォーム・ニュース投稿機能を希望しています。納期は来年 3 月末を
想定しております。よろしくお願いいたします。
```

### 分類結果

| 軸 | 値 |
|---|---|
| category | 見積もり依頼 |
| urgency | 中 |
| sentiment | ニュートラル |
| recommended_response_deadline | 24時間以内 |

### ドラフト返信(Draft Normal ルート)

```
山田花子様

この度はお問い合わせいただき、ありがとうございます。

コーポレートサイトのリニューアルに関するご相談、承知いたしました。
ページ数10〜15ページ、お問い合わせフォーム・ニュース投稿機能のご実装、
納期は来年3月末というご要件、確認させていただきました。

概算見積りのご提供に向けて、以下の点についてご教示いただけますでしょうか。
現在のサイトの有無、既存サイトがある場合はデザイン刷新の希望度合い、
また想定されている予算帯があればお聞かせください。これらの情報により、
より正確なご提案が可能になります。

ご回答いただきましたら、1営業日以内に概算見積りをお送りさせていただく予定です。

よろしくお願いいたします。

〇〇株式会社 カスタマーサポート
```

→ 受領確認 + 不足情報の質問 + 1 営業日以内の予告。営業のテンプレ反応として整っている。

## ケース 3: 感謝ベース + おまけ質問(質問・低)

### 入力メール

```
From: 高橋ゆかり <takahashi@example.org>
Subject: いつも便利に使わせていただいています

貴社のツールを 1 年ほど使わせていただいており、業務効率が大きく改善しました。
本当にありがとうございます。1 点だけ、CSV エクスポート機能の出力項目を
カスタマイズすることは可能でしょうか?お手すきの際で構いませんので、
お返事いただけると嬉しいです。
```

### 分類結果

| 軸 | 値 |
|---|---|
| category | 質問 |
| urgency | 低 |
| sentiment | ポジティブ |
| recommended_response_deadline | 3営業日以内 |

### ドラフト返信(Draft Simple ルート)

```
高橋ゆかり様

いつもご利用いただきありがとうございます。ご好評をいただき大変嬉しいです。

CSV エクスポート機能の出力項目カスタマイズについてですが、現在のバージョンでは
標準項目での出力となっております。ただし、お客様のご要望に応じた対応が可能な
場合もございますので、具体的にどの項目のカスタマイズをご希望されているのか
教えていただけますでしょうか。詳しくお伺いした上で、最適なご提案を
させていただきます。

〇〇株式会社 カスタマーサポート
```

→ 感謝への返礼 → 簡潔な事実回答 → 詳細ヒアリングで深掘り。Urgent の謝罪・冗長さがない、低緊急度に最適化されたトーン。

## ケース 4: 苦情 + 見積依頼の混在(苦情・高)

### 入力メール

```
From: 中村大輔 <nakamura@example.co.jp>
Subject: 前回の不具合と追加発注の件

先月納品いただいた資料に誤字が複数ありました。これは正直対応として残念です。
社内でも問題になっています。なお、別件で来期分の追加発注を検討しているのですが、
こちらの見積りもいただけますでしょうか。
```

### 分類結果

| 軸 | 値 |
|---|---|
| category | 苦情(混在しているが「迷ったら 1 段階上」ルールで苦情扱い) |
| urgency | 高 |
| sentiment | ネガティブ |
| recommended_response_deadline | 2時間以内 |

### ドラフト返信(Draft Urgent ルート)

```
ご不便をおかけし申し訳ございません。先月納品の資料における誤字の件、
重く受け止めております。直ちに該当箇所を確認し、原因究明と改善策の検討を進めます。

つきましては、対象となる資料名と具体的な誤字箇所をお知らせいただけますでしょうか。
これにより、より正確で迅速な対応が可能になります。

同時に、来期分の追加発注に関するご見積りについても、本日中にご連絡させていただきます。
ご発注内容の詳細(数量、仕様等)をご教示いただければ、明日午前中までに見積書をお送りいたします。

貴社のご信頼を取り戻すべく、全力で対応させていただきます。

〇〇株式会社 カスタマーサポート
```

→ 苦情への謝罪先行 + 見積依頼への並行回答。「混在ケースを片方に潰さず両方拾う」設計が動作している証拠。

---

## まとめ

3 つの分岐ルート(Urgent / Normal / Simple)が設計通りに緊急度に応じたトーンを切り替えている。
特に **混在ケース 4** は人間オペレータが見落としやすいパターン(苦情の中に隠れた営業機会)を
両方拾えており、人間レビューの効率化価値が高い。
